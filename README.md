📊 Customer Behavior Dashboard

This project presents an interactive Customer Behavior Dashboard built using Python, SQL, and Power BI to analyze customer demographics, purchasing behavior, and subscription trends. The dashboard provides analysts and business teams with key insights into customer spending patterns, product category performance, and engagement across age groups.

🔍 Project Overview

This dashboard provides comprehensive insights into:

Customer Base Size & Average Purchase Amount
Average Review Rating
Subscription Status Breakdown
Revenue & Sales by Product Category
Revenue & Sales by Age Group
Customer Segmentation by Gender, Category, and Shipping Type

🛠 Tools & Technologies

Python – Data cleaning, preprocessing, and exploratory data analysis
SQL – Data querying, transformation, and validation
Power BI – Data modeling, DAX measures, interactive dashboard development, and visualization

📈 Key Insights & Features

KPI Cards displaying:
Number of Customers (3.9K)
Average Purchase Amount ($59.76)
Average Review Rating (3.75)
Interactive slicers for:
Subscription Status
Gender
Category
Shipping Type
Donut chart breakdown of customers by subscription status (27% subscribed, 73% not subscribed)
Revenue and sales comparison across 4 product categories (Clothing, Accessories, Footwear, Outerwear)
Revenue and sales breakdown by age group (Young Adult, Middle-aged, Adult, Senior)
Dynamic filtering for demographic and behavioral analysis

🚀 Outcome

This dashboard enables users to:

Identify which customer segments drive the most revenue
Understand subscription adoption trends across the customer base
Compare product category performance by sales and revenue
Pinpoint top-spending age groups (Young Adults leading revenue and sales)
Support data-driven marketing and retention strategies through interactive visualizations
